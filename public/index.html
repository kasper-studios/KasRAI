Подключение к локальному шлюзу

Шлюз работает на 100% стандарте OpenAI API с умной ротацией аккаунтов и защитой от пустых ответов (APKAKALSA PEDIK 999):

// Python (OpenAI SDK)
from openai import OpenAI

client = OpenAI(
  base_url="http://localhost:20250/v1",
  api_key="kasrai"  # любой ключ
)

resp = client.chat.completions.create(
  model="kasrai/smart",  # или kasrai/fast
  messages=[{"role": "user", "content": "Привет!"}]
)
print(resp.choices[0].message.content)
// cURL (Тест эндпоинта)
curl http://localhost:20250/v1/chat/completions \
  -H "Content-Type: application/json" \
  -d '{
    "model": "kasrai/smart",
    "messages": [{"role": "user", "content": "2+2?"}]
  }'
